# The Eye Within Words — Cosmic Reality 👁️🌌

This project is an immersive, interactive generative typography simulation built entirely with HTML5 Canvas and Vanilla JavaScript. What appears to be a giant, living cosmic eye is actually constructed from thousands of procedurally placed philosophical words and quotes about consciousness and the universe.

### ✨ The Experience

* **Generative Typography:** 100% of the visual elements—including the deep space background, luminous sclera, electric blue/cyan iris, and dark pupil—are built purely from text.


* **Cinematic Floating Camera:** The simulation features a smooth, continuous camera zoom driven by a gentle sine wave, creating a calm, floating atmospheric effect rather than a jarring loop.


* **Interactive Gaze Tracking:** The eye actively follows the user's cursor or touch input, dynamically shifting the pupil and iris within the bounds of the eyelid clipping path.


* **Biological Blinking System:** A procedural blink controller manages natural, unpredictable blinking intervals between 3 and 6 seconds, complete with a 20% chance of quick double blinks.


* **Cosmic Theming:** The aesthetic is driven by a deep space color palette of midnight blues, cyans, and violets, utilizing vocabulary like "eternity," "perception," and "radiance".



### ⚙️ Technical Details

* **High-Performance Rendering:** To maintain smooth frame rates while rendering thousands of individual text elements, the heavy typographic clusters are drawn to off-screen canvases at initialization.


* **Real-time Compositing:** The main loop composites, masks, and transforms these pre-rendered layers in real-time, calculating quadratic bezier curves for the animated eyelids on every frame.


* **Tech Stack:** Built with standard HTML5 Canvas, Vanilla JavaScript, and CSS3 for the start screen UI.



### 🚀 How to Run

1. Open the HTML file in any modern web browser.
2. Click the "reality theme cosmic l" button on the start screen to initiate the simulation.


3. Move your cursor across the screen to guide the eye's gaze.
